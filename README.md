# Koboo Tax Calculator

A focused Nigerian tax calculator that shows your real take-home pay with clarity and confidence.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS** (with custom design system)
- **Google Fonts** (DM Serif Display + DM Sans)

## Project Structure

- `/app` - Next.js app directory with pages and layout
- `/app/globals.css` - Global styles and Tailwind configuration
- `/app/layout.tsx` - Root layout with navigation and footer
- `/app/page.tsx` - Landing page
- `/app/calculator` - Calculator page (coming soon)
- `/app/how-it-works` - Methodology explanation
- `/app/deductions` - Deductions guide
- `/app/employers` - Employer-focused features
- `/app/pricing` - Pricing information

## Design Philosophy

Koboo follows an ultra-minimalist, editorial-inspired aesthetic:
- High-contrast typography with character-rich fonts
- Purposeful spacing and layout
- Subtle background textures and grid lines
- Mobile-first responsive design
- Clear, honest communication about tax calculations
